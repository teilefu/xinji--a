# 星迹日历 · GitHub 云打包操作指南（全程不用装任何软件）

> 原理：把代码传到 GitHub，GitHub 的免费服务器帮你自动打包成 APK（安卓安装包），完成后你在网页上直接下载。
> 全程大约：注册5分钟 + 上传5分钟 + 等待打包20~30分钟。

---

## 第1步：注册 GitHub 账号（免费）

1. 浏览器打开：`https://github.com`
2. 点右上角 **Sign up**，用邮箱注册（邮箱、密码、用户名）
3. 注册完会要你验证邮箱（点邮件里的链接）

---

## 第2步：新建一个仓库（就是新建一个网盘文件夹）

1. 登录后点右上角 **+** → **New repository**
2. Repository name 填：`xingji-calendar`（随便填也行）
3. 选 **Public**（公开，免费无限流量）
4. 其他不用动，点底部绿色按钮 **Create repository** 创建

---

## 第3步：把源码文件夹整个拖进去上传

1. 在你电脑上新建一个文件夹，名字叫 `xingji`，把下面这些**原样放进去**（一个都不能少）：

```
xingji/
├── .github/
│   └── workflows/
│       └── build-apk.yml     ← 云端打包的"指令书"
├── main.py                    ← App全部代码
├── buildozer.spec             ← 安卓打包配置
├── app_icon.png               ← 你的星空图标
├── NotoSansSC-Regular.otf     ← 中文字体
├── NotoSansSC-Bold.otf        ← 中文字体（加粗）
└── 安卓打包步骤.md             ← 这个可以不传，传了也没事
```

2. 回到刚创建的仓库页面，点 **Add file** → **Upload files**
3. **把整个 `xingji` 文件夹拖进上传框**（GitHub 会自动保留里面的文件夹结构）
4. 等文件传完（字体文件大，稍等），滚动到底部点绿色按钮 **Commit changes**

> 上传界面只显示文件不显示文件夹是正常的，传完自动建好。

---

## 第4步：自动打包（你只需要等）

1. 上传完成回到仓库主页，点顶部的 **Actions** 标签
2. 能看到一个黄色/蓝色的任务在跑（名字叫"打包星迹日历APK"），点进去能看到日志
3. **等20~30分钟**，看到绿色 ✓ 就是打包成功
4. 如果显示红色 ✗，点开日志把**红色报错文字**截图发给我，我帮你改

---

## 第5步：下载 APK 装到手机

1. 打包成功（绿色 ✓）后，点开这个任务
2. 最下面有一个 **Artifacts（构建产物）** 区域，里面有 `星迹日历-APK`
3. 点它下载一个 zip 压缩包，解压后里面就是：
   ```
   xingjirili-0.1.0-arm64-v8a-debug.apk
   ```
4. 通过微信/QQ 把这个 .apk 发到手机，或插数据线复制
5. 手机点击安装，提示"未知来源"就允许，装完桌面出现 **星迹日历** 🌟（图标就是你的星空图）

---

## 常见问题

| 问题 | 解决办法 |
|---|---|
| 上传时提示文件太大 | GitHub 单文件限100MB，我们的字体才16MB，不会超 |
| Actions 里看不到任务 | 确认第3步的 `.github/workflows/build-apk.yml` 传上去了（这是个隐藏文件夹，传的时候把整个xingji文件夹拖进去就自动带上） |
| 打包报错 | 截图红色报错发我 |
| 想更新App功能 | 以后改代码后，重新拖文件上传，GitHub 会自动重新打包 |

---

## 之后每次打包
改完代码 → 上传覆盖旧文件 → Actions 自动重新打包 → 下载新APK。不需要你做任何配置。
