# 星迹日历 · 安卓版打包教程（Windows 电脑）

> 你电脑上的 `android_app` 文件夹里已经有全部源码和配置：
> - `main.py` —— App 全部代码
> - `buildozer.spec` —— 安卓打包配置（含图标）
> - `app_icon.png` —— 你自制的星空图标
> - `NotoSansSC-Regular.otf` / `NotoSansSC-Bold.otf` —— 中文字体（安卓上显示中文必需）

打包安卓 APK 需要 Linux 环境，Windows 用 **WSL2（内置Linux子系统）** 即可，官方免费方案。全程约 40~90 分钟（第一次要下载安卓SDK，之后每次打包只需几分钟）。

---

## 第一步：安装 WSL2（Windows 10/11 都支持）

1. 右键开始菜单 → **Windows PowerShell（管理员）**
2. 输入下面命令回车，等待安装 Ubuntu：
   ```
   wsl --install -d Ubuntu
   ```
3. 安装完会要求**重启电脑**
4. 重启后自动打开 Ubuntu 窗口，**设置一个用户名和密码**（密码输入时屏幕不显示，正常）

> 如果 `wsl --install` 报错，先执行 `wsl --update` 再重试。

---

## 第二步：在 Ubuntu 里安装打包工具

打开 Ubuntu 窗口（开始菜单搜索 "Ubuntu"），逐条复制粘贴执行：

```bash
sudo apt update
```
输入密码回车，等它跑完。然后：

```bash
sudo apt install -y python3-pip python3-venv git zip unzip openjdk-17-jdk autoconf libtool pkg-config zlib1g-dev libncurses-dev libffi-dev libssl-dev
```
（大约 5~10 分钟）

```bash
pip install --user buildozer cython
```

---

## 第三步：把源码放进 Ubuntu

1. 你的源码在 Windows 的：
   `C:\Users\你的用户名\Desktop\新建文件夹\纪念日日历软件\android_app`
2. 在 Ubuntu 里输入下面命令，把整个文件夹复制到 Ubuntu 主目录：
   ```bash
   cp -r /mnt/c/Users/你的用户名/Desktop/新建文件夹/纪念日日历软件/android_app ~/xingji
   ```
   > 路径里"你的用户名"换成你的Windows用户名（英文）。如果桌面路径不同，先到 Windows 里确认文件夹位置。
3. 进入文件夹：
   ```bash
   cd ~/xingji
   ls
   ```
   应该能看到 `main.py`、`buildozer.spec`、`app_icon.png` 等文件。

---

## 第四步：开始打包 APK

在 `~/xingji` 目录下执行：

```bash
buildozer -v android debug
```

- **第一次**会自动下载 Android SDK / NDK（几个GB，30~60分钟，网速决定）
- 之后会显示很多英文日志，**最后出现 `APK built` 就是成功**
- 中间如果下载中断，重新执行这条命令会自动续传

打包成功的 APK 在：
```
~/xingji/bin/xingjirili-0.1.0-arm64-v8a-debug.apk
```

把它复制回 Windows 桌面：
```bash
cp ~/xingji/bin/*.apk /mnt/c/Users/你的用户名/Desktop/
```

---

## 第五步：装到手机

1. 把 `xingjirili-0.1.0-arm64-v8a-debug.apk` 通过微信/QQ发到手机，或插数据线复制
2. 手机点击这个文件安装
3. 如果提示"未知来源"，去设置里**允许安装未知应用**（点允许即可）
4. 安装完成，桌面出现 **星迹日历**（图标就是你的星空图）🌟

---

## 常见问题

| 问题 | 解决办法 |
|---|---|
| 提示 `Java not found` | 回到第二步，确认 openjdk-17-jdk 装好了 |
| 下载太慢/中断 | 网络原因，重跑 `buildozer -v android debug` 会续传 |
| 提示 `Command 'buildozer' not found` | 输入 `export PATH=$PATH:$HOME/.local/bin` 再试 |
| 打包到一半报错 | 把**红色报错文字**复制发给我，我帮你看 |

## 使用说明（装好之后）

- 打开 App 默认显示**当月日历**：阳历+阴历、当天红点、节气/节日标注
- 左上角 **年视图** 按钮 → 12个月总览 → 点某天跳回月历
- 底部 **纪念日** 标签 → 左右滑动卡片流（倒计时+经历天数）
- 右上角 **＋** → 添加纪念日：命名、图片、阳历/阴历起始日、每年/单次、阳历/阴历提醒
- 底部 **节假日** 标签 → 法定节假日+24节气，全部带倒计时
- 到纪念日当天打开App，会弹**手机通知**提醒
- 数据全部存在手机本地（`/data/data/org.xingji.xingjirili/`），无需联网、无需登录

> 提醒：当前通知是"打开App时检查并弹窗"。要让App在后台也自动提醒，需要加安卓后台服务，属于进阶功能，先用着看效果，需要再加。
